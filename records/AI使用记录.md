# AI 使用记录（开发过程原始素材）

> 本文件记录开发过程中向 AI 发出的关键指令（提示词）与 AI 输出摘要，作为最终《AI使用情况报告》的原始素材。
> 最终报告的表述与贡献度由本人审阅调整。

## 关键提示词记录

### 第1条｜需求理解与功能拆解阶段
- **提示词**：向 AI 提供《课堂学情监控管理系统产品要求文档》全文，要求"严格基于文档拆解成可实现的功能点清单，按学生端、教师端、管理员端分类，每个功能点一句话说明，禁止扩展文档外需求，不要技术实现内容"。
- **AI 输出摘要**：按三端角色输出结构化功能清单（学生3项、教师5项、管理员2项、公共约束），后整理为 docs/01。
- **自行修正**：无，清单逐条对照 PRD 核对无遗漏。

### 第2条｜系统架构与模块分解
- **提示词**："技术栈用 Java SpringBoot + MySQL + 原生HTML/CSS/JS，给出分层架构、按功能模块拆分核心类/接口、说明前后端交互方式，不生成代码"。
- **AI 输出摘要**：给出 Controller/Service/Mapper/Entity 分层、8 个功能模块划分、统一 JSON 返回 {code,message,data}、Token 会话方案，整理为 docs/02。
- **自行修正**：将定时统计从固定 @Scheduled 改为 SchedulingConfigurer 动态读取配置周期。

### 第3条｜数据库设计
- **提示词**："设计 MySQL 表结构，包含用户表（三类角色）、学情反馈表、统计表、讨论消息表，字段严格对应 PRD，标注主键外键类型注释，输出完整建表 SQL"。
- **AI 输出摘要**：生成 sys_user、feedback、statistics、discussion_message、sys_config 等表，后补充拓展模块 course/class_info/class_student 三表，形成 database/schema.sql。
- **自行修正**：密码字段改为 MD5 加盐存储；统计表用 score1_count~score6_count 六列存分布；补充测试数据。

### 第4条｜认证模块后端（代码生成）
- **提示词**："实现登录认证：密码、短信验证码、微信/QQ 第三方三种方式；登录后 Token 会话；拦截器实现登录校验和角色权限隔离（学生/教师/管理员）；统一 JSON 返回；包含参数校验与异常处理"。
- **AI 输出摘要**：生成 AuthController/AuthService、TokenStore、SmsCodeStore、LoginInterceptor、WebConfig、PasswordUtil(MD5+盐)、SysUser 实体/Mapper 等。
- **自行修正**：短信与第三方无真实服务资质，改为模拟实现（验证码内存存储并在响应中返回演示；第三方用绑定手机号模拟授权）；拦截器业务状态码 401/403 放在 JSON body。

### 第5条｜认证模块前端
- **提示词**："写登录页，三个标签页（密码/短信/第三方），登录成功按角色跳转对应首页；公共 JS 封装 fetch 自动带 token、401 跳登录；样式简洁"。
- **AI 输出摘要**：生成 login.html（三标签+验证码倒计时+模拟授权）、common.js、style.css、三端占位首页。
- **自行修正**：补充测试账号提示、已登录自动跳转、角色不符自动跳回对应首页。

### 第6条｜学情反馈与定时统计（后端）
- **提示词**："实现学生6档表情反馈提交（1-6分）；教师端按周期统计：每个学生每门课取最后一次反馈，计算提交人数、各分数段人数、平均分、总体方差，结果存快照表；统计周期5-10分钟管理员可配、改配置不用重启；提供教师手动立即统计接口"。
- **AI 输出摘要**：Feedback/Statistics/SysConfig/Course 实体与 Mapper、FeedbackService、StatsService（分组聚合+均值方差）、SchedulingConfigurer 动态触发器、Feedback/Statistics/Config/Course 控制器。
- **自行修正**：动态触发器初版误用 Spring 旧版 API（PeriodicTrigger 的 setPeriod/nextExecutionTimeInMillis 在 Spring Boot 3 已移除），编译报错后改为实现 Trigger 函数式接口、nextExecution 返回 Instant。

### 第7条｜统计可视化（前端）
- **提示词**："教师端当前时段学情用高亮卡片显著展示人数/平均分/方差，6个表情显示各分数人数和占比，用 ECharts 画柱状图和饼状图，可按课程筛选、手动立即统计、30秒自动刷新；学生端6个大表情按钮提交并可看自己的记录；管理员端配置5-10分钟统计周期"。
- **AI 输出摘要**：重写 student/teacher/admin 三个 home.html（页签式），ECharts 5.5.1 下载到本地 static/js 离线加载。
- **自行修正**：历史查询/导出页签先搭好表格与查询表单，导出接口留待任务6对接。

### 第8条｜历史查询与 Excel 导出
- **提示词**："教师按课程+起止时间组合查询历史统计快照；用 Apache POI 把查询结果导出为 .xlsx，包含标题行、加粗表头（统计时间/课程/人数/均分/方差/1-6分人数）、数据行，中文不能乱码，文件名用中文并通过浏览器正确下载；前端用带 token 的 fetch 下载文件"。
- **AI 输出摘要**：新增 StatsExportService（XSSFWorkbook 生成、合并标题、表头样式、列宽自适应、数值单元格）、StatisticsController 增加 /export 接口（Content-Disposition 用 filename*=UTF-8'' 编码中文文件名），前端解析响应头文件名并下载。
- **自行修正**：导出数据改为按统计时间正序（便于在 Excel 看趋势）；数字指标用数值型单元格而非字符串；前端补充空结果与文件名时间戳兜底。

### 第9条｜在线讨论区（文字+图片）
- **提示词**："实现学生和教师共用的在线讨论区：可发文字和图片，消息显示发送人姓名和角色（学生/教师徽标）、内容、图片、时间；前端约3秒轮询实现实时刷新，自己的消息靠右；图片上传到本地 uploads 目录，限制10MB、仅允许常见图片格式、文件名用UUID；未登录不能访问"。
- **AI 输出摘要**：DiscussionMessage 实体/VO/Mapper（join sys_user 取姓名角色）、DiscussionService（空消息校验、字数限制、正序返回）、FileStorageService（UUID存储、格式/大小白名单）、DiscussionController（消息收发+上传）、WebConfig 增加 /uploads/** 静态映射、共享前端 discuss.js 与聊天气泡样式。
- **自行修正**：消息发送人身份一律取自服务端登录态而非前端传参（防伪造）；前端对消息文本和姓名做 HTML 转义防 XSS；轮询在页面不可见时暂停；上传超限补充全局异常处理返回友好提示。

### 第10条｜管理员用户管理
- **提示词**："实现管理员对学生/教师/管理员三类账号的增删改查：可按角色筛选、按账号/姓名/手机号搜索；新增和编辑用弹窗，学生角色额外显示学号/年级/班级/专业字段；新增用户默认密码123456、账号唯一；可启用禁用账号；删除用户时级联清理其反馈、讨论消息和班级关联；管理员不能删除或禁用自己；接口仅管理员可访问"。
- **AI 输出摘要**：UserDTO、UserManageService（角色化必填校验、账号唯一、密码加密、事务级联删除、自我保护）、UserManageController（列表/新增/修改/删除/启禁），重写 admin/home.html 用户管理页签（角色筛选、搜索、表格、弹窗、状态标签）。
- **自行修正**：删除用户时统计快照作为历史数据保留（快照不引用用户），仅清理反馈、讨论消息、班级关联三类有外键约束的数据；联系方式补充11位手机号格式校验；编辑时角色字段锁定不可变更。

### 第11条｜拓展模块：课程与班级管理
- **提示词**："实现自主拓展模块课程与班级管理：教师维护我的课程（增删改），每门课程下建班级（增删），每个班级维护学生名单（从全校学生中批量勾选加入、自动去重、可移除）；教师只能操作自己名下的课程班级；学生端可查看自己加入的课程与所在班级；删除课程时事务级联清理班级和名单，该课程已有反馈归入默认课堂；学生按课程提交的反馈要能按课程维度统计"。
- **AI 输出摘要**：ClassInfo/ClassStudent 实体与 Mapper（名单 join、学生课程行查询）、CourseDTO/ClassDTO/AddStudentsDTO/StudentCourseVO、CourseManageService（三级操作+归属校验+事务级联）、教师 CourseManageController 与学生 StudentCourseController；教师端三列钻取式管理界面（课程/班级/名单+三个弹窗），学生端我的课程卡片。
- **自行修正**：删除课程时反馈不直接删除，而是把 course_id 置空归入默认课堂，保留学生反馈数据；班级与课程都冗余 teacher_id 以便归属校验；添加学生逐个校验存在性与角色，重复加入跳过并返回实际加入人数。

## 调试记录

### 认证模块联调（16 项接口测试全部通过）
- 正确/错误密码、账号不存在、未登录 401、学生越权教师接口 403、短信验证码正确/错误/未注册、微信与 QQ 模拟登录、未绑定手机号、登出失效、禁用账号拦截、静态页面可访问。
- 发现并修复：初始 schema.sql 中密码哈希为占位值，与 MD5+盐算法不一致，重新计算 `MD5("classcheck"+"123456")=9743c9b2...` 并更新全部测试账号后登录正常。

### 学情统计联调（统计数值全部手算核对一致）
- 造数：课程1 三名学生最终反馈 4/5/3 分 → 实测人数3、均分4.00、总体方差0.6667、3/4/5分各1人，与手算一致；默认课堂 2/6 分 → 人数2、均分4.00、方差4.00；课程2 种子 5/3 分 → 人数2、均分4.00、方差1.00。
- **缺陷1（去重错误）**：同一学生同一秒内两次提交时，按 `MAX(create_time)` 关联会把同秒的两条都计入，人数虚增（实测4而非3）。改为按自增主键 `MAX(id)` 判定最新反馈，修复。
- **缺陷2（快照/记录排序不确定）**：两次统计在同一秒触发导致 `stat_time` 相同，"最新快照"可能取到旧数据；反馈记录同秒提交顺序也不稳定。统一增加 `id 倒序` 作为兜底排序，修复。
- 周期配置：默认5分钟，改8/10生效，填3或11被拒（校验5-10）。

### 历史查询与导出验证（任务6）
- 连续生成3期统计后：全部快照10条、课程1为4条、课程1+当天时间范围4条、2030未来范围0条，组合筛选全部符合预期。
- 导出 .xlsx 用解压方式校验 sharedStrings：标题行、11个中文表头无乱码，数据行数值正确（Java均分5.00/方差0.6667、数据库原理4.00/1.0、数据结构6.00/0）；全部导出10行、按课程导出4行，与查询一致；未登录请求返回401。

### 讨论区验证（任务7）
- 文字消息收发、空消息被拒；合法 PNG 上传成功并通过 /uploads/** 访问（200）；.txt 非图片被拒；11MB 文件被拦截并返回"图片不能超过10MB"；带图消息正常展示；分页 limit/offset 正确；未登录 401。
- **缺陷（列表500）**：消息列表接口首次返回系统异常，定位为 Mapper 中 join sys_user 误用了不存在的列 `real_name`（实际列名为 `name`），修正后列表正常返回发送人姓名与角色。

### 用户管理验证（任务8，19项接口测试全部通过）
- 列表：全部8人、按角色学生5人、关键字 teacher 命中2人；新增学生缺学号被拒、重复账号被拒；合法新增学生/教师成功并用默认密码123456登录成功。
- 编辑：改专业并重置密码后旧密码登录失败、新密码成功；禁用后登录被拒（"账号已禁用"），重新启用后恢复。
- 自我保护：管理员删除/禁用自己均被拒；级联删除：删除带反馈和讨论消息的 student01 无外键报错；学生越权访问返回403、未登录返回401。
- **缺陷（编译失败）**：服务中误用了不存在的方法 `PasswordUtil.hash()`（实际方法名为 `encrypt()`），编译报错后修正。

### 课程班级管理验证（任务9，15项断言全部通过）
- 教师课程归属：teacher01 名下2门、teacher02 名下1门；新建课程/班级成功，空名称被拒；批量加学生1,2,3后名单正确，重复加入3,4自动去重（名单4人），移除后变3人，加入不存在学生被拒。
