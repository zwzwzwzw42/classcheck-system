## 1. 作业概览

- **项目名称**：课堂学情监控管理系统（课程大作业）
- **开发模式**：混合模式（Spec 驱动设计 + Vibe Coding 小步迭代实现）
- **技术栈**：Java 21 + Spring Boot 3.3 + MySQL 8 + 原生 HTML/CSS/JS（ECharts 图表，POI 导出 Excel）
- **项目目录**：`D:\classcheck_system`（git 仓库，分支 master）
- **要求依据**：产品要求文档.pdf、SPEC驱动开发使用指导手册.pdf、VIBE驱动开发使用指导手册.pdf、课堂学情监控管理系统大作业清单.pdf

## 2. 功能要求（必做基础功能）

| 端 | 功能 |
|---|---|
| 学生端 | 6档表情学情反馈（1-6分对应理解程度，6=完全理解/1=完全没理解）；在线讨论区（文字+图片）；三种登录方式（密码/短信验证码/微信QQ第三方模拟） |
| 教师端 | 实时学情统计+可视化（数字、表情、柱状图、饼状图）；指标含提交人数、各分数段人数、平均分、方差；按课程+时间组合查历史学情；导出Excel；参与在线讨论 |
| 管理员端 | 学生/教师/管理员三类账号增删改查（字段按PRD）；统计刷新周期配置（5-10分钟） |
| 系统公共 | 全功能登录后访问；角色权限隔离；定时统计（周期管理员可配）；200并发、核心操作<1秒 |

## 3. 拓展模块（自主新增，必做）

- **选定模块**：课程与班级管理
- **内容**：教师维护名下课程/班级/班级学生名单；学生查看自己加入的课程班级并按课程提交反馈；学情统计按课程维度独立计算与查询
- **新增数据表**：course、class_info、class_student（3张）
- **要求**：独立业务逻辑、完整前后端流程、可运行可演示、开发过程记录进 AI 使用报告

## 4. 提交物清单（7项，缺一不可）

1. 完整源代码（结构清晰、注释完整、可直接编译运行）
2. 数据库脚本（建表SQL+初始化测试数据，导入即运行）
3. 系统运行截图 ≥8张 或 演示视频 ≥3分钟
4. 用户使用手册（学生/教师/管理员，配操作截图）
5. 系统安装调试手册（环境、依赖、部署、排错）
6. 新增业务模块说明文档（≥500字）
7. AI使用情况报告（按模板，≥5条关键提示词、贡献度、错误修正案例、原创声明）

**打包**：`学号_姓名_课堂学情监控系统.zip`，内含 源代码/、文档/、截图与视频/ 子文件夹。
