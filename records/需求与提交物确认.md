## 一、项目要实现的功能

### 1. 基础功能（必做，严格按产品要求文档）

**学生端（移动端/PC 浏览器）**

| 功能 | 要求 |
|---|---|
| 6档表情学情反馈 | 6类表情一一对应 1-6 分：6=完全理解、5=较好、4=基本、3=部分、2=较低、1=完全没理解；学生选择表情提交当前课堂理解状态 |
| 在线讨论区 | 与教师实时互动，支持发送文字、图片两类消息 |
| 多方式登录 | 密码认证、短信验证码认证、第三方账号认证（微信、QQ） |

**教师端（PC 浏览器）**

| 功能 | 要求 |
|---|---|
| 实时学情统计 | 查看当前时段统计结果，指标包含：提交表情的学生总人数、各分数段（对应表情）分布人数、班级平均分、分数方差 |
| 可视化图表 | 统计结果以数字、表情、图表三种形式展示；图表至少包含柱状图、饼状图两类；当前时段结果在界面显著位置高亮展示 |
| 历史学情查询 | 按上课时间、课程名称两个维度组合查询历史学情统计 |
| Excel 导出 | 将查询结果导出为 Excel 格式文档 |
| 在线讨论 | 参与课堂在线讨论，发送文字、图片消息 |

**管理员端（PC 浏览器）**

| 功能 | 要求 |
|---|---|
| 用户账号管理 | 对学生、教师、管理员三类用户执行添加、删除、修改、查询；学生字段：编号、学号、姓名、年龄、性别、年级、班级、专业、联系方式；教师/管理员字段：编号、姓名、年龄、性别、联系方式 |
| 统计周期配置 | 配置学情统计刷新周期，取值范围 5-10 分钟 |

**系统公共**

| 功能 | 要求 |
|---|---|
| 身份认证 | 所有功能必须登录后访问，禁止匿名访问业务数据 |
| 权限隔离 | 不同角色权限隔离，禁止越权操作 |
| 定时统计 | 按管理员配置的周期自动统计全班学情数据 |
| 性能 | 支持 200 人同时在线；核心操作响应 < 1 秒 |

### 2. 拓展模块（必做，自主新增）：课程与班级管理

- 教师端：课程增删改查、为课程创建班级、维护班级学生名单（添加/移除学生）
- 学生端：查看自己已加入的课程与班级；提交反馈时选择所属课程
- 联动：学情统计按课程维度独立计算与查询
- 新增数据表：course（课程）、class_info（班级）、class_student（班级-学生关联）
- 要求：独立业务逻辑、完整前后端交互流程、可运行可演示

### 3. 非功能确认

- 技术栈：Java 21 + Spring Boot 3.3 + MySQL 8 + 原生 HTML/CSS/JS（ECharts 图表、POI 导出）
- 终端：学生端移动/PC 浏览器；教师端、管理员端 PC 浏览器
- 开发模式：混合模式（Spec 设计 + Vibe 迭代），已确认
