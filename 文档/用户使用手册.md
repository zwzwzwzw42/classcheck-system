## 1. 系统简介

**课堂学情监控管理系统**是一套面向课堂教学场景的学情采集与分析平台，用于解决传统课堂中教师难以实时掌握学生理解程度的问题。

### 1.1 核心功能

| 角色 | 功能 |
|---|---|
| 学生 | 6 档表情反馈提交、查看个人反馈记录、参与在线讨论、查看我的课程与班级 |
| 教师 | 实时学情统计（人数/均分/方差/分布 + 图表）、历史学情查询与 Excel 导出、参与在线讨论、课程→班级→学生名单三级管理 |
| 管理员 | 三类账号（学生/教师/管理员）增删改查与启用禁用、学情统计周期配置 |

### 1.2 技术架构

- **后端**：Java 21 + Spring Boot 3.3 + MyBatis-Plus + MySQL 8
- **前端**：原生 HTML / CSS / JavaScript（ECharts 图表、Apache POI 导出 Excel）
- **特色**：三种登录方式、Token 会话、角色权限隔离、定时统计（周期可配）

### 1.3 六档表情与分值

| 表情 | 分值 | 含义 |
|---|---|---|
| 😣 | 1 | 完全没理解 |
| 😕 | 2 | 理解程度较低 |
| 😐 | 3 | 部分理解 |
| 🙂 | 4 | 基本理解 |
| 😊 | 5 | 理解较好 |
| 😄 | 6 | 完全理解 |

## 2. 运行环境与启动

### 2.1 环境要求

| 软件 | 版本要求 |
|---|---|
| JDK | 17 及以上（推荐 21） |
| MySQL | 8.0 |
| Maven | 3.6+ |
| 浏览器 | Chrome / Edge 等现代浏览器 |

### 2.2 初始化数据库

1. 启动 MySQL 服务；
2. 在 MySQL 中执行建库与初始化脚本（含 8 张表和测试数据）：

```sql
-- 在 MySQL 命令行中执行
source D:/classcheck_system/database/schema.sql;
```

### 2.3 启动系统

在项目根目录执行（或使用 IDEA 打开 `backend/pom.xml` 后运行 `ClasscheckApplication`）：

```bash
cd D:\classcheck_system\backend
D:\classcheck_system\tools\apache-maven-3.9.9\bin\mvn.cmd spring-boot:run
```

启动成功后，浏览器访问：**http://localhost:8080**

> 可通过 `http://localhost:8080/api/health` 检查系统是否正常运行（返回 `数据库连接正常` 即 OK）。

## 3. 登录系统

打开 `http://localhost:8080` 进入登录页，系统提供 **三种登录方式**（页面顶部页签切换）：

![登录页](..\截图\01_登录页.png)

### 3.1 密码登录（推荐）

1. 切换到「密码登录」页签；
2. 输入用户名和密码（密码默认统一为 `123456`）；
3. 点击「登 录」，系统将按角色自动跳转到对应首页。

### 3.2 短信验证码登录

1. 切换到「短信登录」页签；
2. 输入已注册手机号，点击「获取验证码」；
3. 输入收到的 6 位验证码，点击「登 录」。
   > 演示环境下验证码由系统模拟发送（页面上会直接提示验证码），验证码 5 分钟内有效。

### 3.3 第三方（微信/QQ）模拟登录

1. 切换到「第三方登录」页签；
2. 点击「微信」或「QQ」图标，弹出模拟授权窗口；
3. 选择已绑定的演示账号并确认授权，即可登录。

### 3.4 测试账号

| 账号 | 角色 | 密码 |
|---|---|---|
| student01 ~ student05 | 学生 | 123456 |
| teacher01 / teacher02 | 教师 | 123456 |
| admin | 管理员 | 123456 |

> 账号被管理员禁用后无法登录；不同角色只能访问自己的功能模块，越权访问会被拦截。

## 4. 学生端使用指南

学生登录后进入学生首页，顶部有 4 个页签：**学情反馈、我的反馈记录、在线讨论、我的课程**。

### 4.1 提交学情反馈

![学生端-学情反馈](..\截图\02_学生端_学情反馈.png)

1. 选择课程（默认「默认课堂」，若教师已把你加入某课程班级，可选择对应课程）；
2. 点击最能代表你当前理解程度的表情（6 档）；
3. 点击「提交反馈」。

> - 可重复提交，同一课程以**最后一次提交**为准；
> - 提交后教师端即可看到最新统计（需等待一个统计周期或教师手动触发统计）。

### 4.2 查看我的反馈记录

切换到「我的反馈记录」页签，可查看最近 50 条自己的提交记录（时间、课程、分值、理解程度）。

### 4.3 参与在线讨论

![学生端-在线讨论](..\截图\04_学生端_在线讨论.png)

1. 在输入框中输入文字，回车或点击「发送」即可发言；
2. 点击「图片」可上传图片（支持 jpg/jpeg/png/gif/webp，≤10MB）；
3. 消息约每 3 秒自动刷新，可实时看到师生互动内容；
4. 自己的消息靠右显示，他人消息靠左，姓名旁有角色徽标（学生蓝/教师橙）。

### 4.4 查看我的课程

![学生端-我的课程](..\截图\03_学生端_我的课程.png)

展示你已加入的课程卡片：课程名称、任课教师、课程简介、所在班级标签。加入课程由任课教师操作。

## 5. 教师端使用指南

教师登录后进入教师首页，有 4 个页签：**实时学情统计、历史查询与导出、在线讨论、课程班级管理**。

### 5.1 实时学情统计

![教师端-实时统计](..\截图\05_教师端_实时统计.png)

1. 顶部选择课程（默认「默认课堂」）；
2. 点击「立即统计」可手动触发一次统计（也可等待系统按周期自动统计）；
3. 页面显著展示三项核心指标：
   - **提交学生人数**：当前周期内提交了反馈的学生数（每人每课去重）；
   - **班级平均分**：所有提交学生分数的平均值（保留 2 位小数）；
   - **分数方差**：总体方差，反映学生理解程度差异大小；
4. 下方展示 6 档表情分布（人数 + 占比）、**柱状图**（各分数人数）和**饼状图**（分数占比）；
5. 页面每 30 秒自动刷新。

### 5.2 历史查询与 Excel 导出

![教师端-历史查询](..\截图\06_教师端_历史查询.png)

1. 选择课程、起止日期后点击「查询」，查看历史统计快照列表；
2. 点击「导出 Excel」，系统下载 `.xlsx` 文件，包含标题行、表头（统计时间/课程/提交人数/平均分/方差/1~6分人数）和全部数据行，可直接用 Excel/WPS 打开分析趋势。

### 5.3 参与在线讨论

同学生端，支持文字与图片，实时刷新，教师发言带「教师」橙色徽标。

### 5.4 课程班级管理（自主拓展模块）

![教师端-课程班级管理](..\截图\07_教师端_课程班级管理.png)

三级钻取式管理：**课程 → 班级 → 学生名单**。

1. **管理课程**：左侧「我的课程」列，点击「+ 新增」创建课程（名称、简介）；点课程右侧「编辑/删除」可修改或删除（删除会级联清理其下班级与名单）；
2. **管理班级**：先点击选中左侧一门课程，中间列显示该课程的班级，点「+ 新增」创建班级；
3. **管理学生名单**：点击选中一个班级，右侧显示名单；点「+ 添加学生」弹出全校学生列表，勾选要加入的学生（已在班级中的默认勾选并标注），保存后自动去重；名单中可「移除」学生。

> 教师只能管理**自己名下**的课程、班级，无法查看或操作其他教师的课程。

## 6. 管理员端使用指南

管理员登录后进入管理员首页，有 2 个页签：**用户管理、系统配置**。

### 6.1 用户管理

![管理员端-用户管理](..\截图\08_管理员端_用户管理.png)

1. **筛选与搜索**：点击「全部/学生/教师/管理员」按角色筛选；在搜索框输入账号/姓名/手机号关键字后回车或点「搜索」；
2. **新增用户**：点「+ 新增用户」弹出表单——
   - 选择角色：学生 / 教师 / 管理员；
   - 学生角色额外填写：学号、年级、班级、专业（学号、班级必填）；
   - 教师/管理员只需填写基础信息（姓名、年龄、性别、联系方式）；
   - 密码留空则默认 `123456`；
3. **编辑用户**：修改用户信息；编辑时角色不可变更，可重置密码（留空表示不改）；
4. **启用/禁用**：禁用后该账号无法登录；可重新启用；
5. **删除用户**：删除用户会同步清理其反馈、讨论消息与班级名单关联（统计历史保留）；**管理员不能删除/禁用自己**（自己的删除、禁用按钮为灰色）。

### 6.2 系统配置

![管理员端-系统配置](..\截图\09_管理员端_系统配置.png)

- 设置学情统计刷新周期（5~10 分钟），保存后**立即生效，无需重启系统**；
- 页面会显示当前生效的统计周期。

## 7. 常见问题 FAQ

**Q1：启动后访问 http://localhost:8080 打不开？**
检查：① MySQL 服务是否启动；② 8080 端口是否被占用（`netstat -ano | findstr 8080`）；③ 是否已执行 schema.sql 初始化数据库。

**Q2：忘记密码怎么办？**
联系管理员在「用户管理」中编辑该用户并重置密码；或使用短信验证码登录（演示环境验证码由系统模拟）。

**Q3：学生提交了反馈，教师端为什么还没看到？**
统计按周期（默认 5 分钟）自动进行，也可在教师端点击「立即统计」手动刷新。

**Q4：为什么删除用户会提示失败？**
若该用户存在反馈/讨论消息/班级关联，系统会自动先清理再删除；如果仍有问题，请确认是否尝试删除自己（系统禁止）。

**Q5：教师看不到某门课程？**
课程按教师归属隔离，只有课程创建者（任课教师）能看到和管理；如需转交，请联系系统管理员或由该课程教师处理。

**Q6：Excel 导出后中文乱码？**
请用 Excel/WPS 打开；本系统导出文件为 UTF-8 编码的 .xlsx，兼容 Office 2016 及以上版本。

**Q7：上传图片失败？**
仅支持 jpg/jpeg/png/gif/webp 格式且不超过 10MB。

## 8. 附录：统计口径说明

| 指标 | 计算方式 |
|---|---|
| 提交人数 total_count | 当前统计周期内，每个学生每门课程**只取最后一次提交**（按最新记录判定）后的人数 |
| 平均分 avg_score | 全部有效反馈分数的算术平均，保留 2 位小数 |
| 方差 variance | 总体方差 = Σ(x-μ)² / N，保留 4 位小数，反映理解程度离散度 |
| 分数分布 score1~6_count | 各分值（1~6 分）分别对应的人数 |
| 统计周期 | 由管理员配置（5~10 分钟），修改后下一个周期自动生效 |
| 课程维度 | 按课程独立统计；未选课程的反馈归入「默认课堂」 |
