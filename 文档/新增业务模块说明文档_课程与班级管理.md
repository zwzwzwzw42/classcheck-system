## 1. 需求背景（本人提出）

原《产品要求文档》中的学情反馈与定时统计均以"全班整体"为统计对象，但在真实教学场景中，一位教师通常同时讲授多门课程、面向多个班级。我注意到原系统存在以下不足：

1. **缺少课程维度**：学生提交反馈时不知道自己反馈的是哪门课，教师端看到的统计结果也无法区分课程，历史数据难以按课程追溯；
2. **班级组织零散**：系统中没有班级概念，教师无法便捷地维护"某门课程 → 某个班级 → 班级学生名单"的组织关系；
3. **学情难以精细化**：不同课程、不同班级的学情应当分开统计与对比，整体统计无法反映单门课程的真实掌握情况。

因此，我提出并设计了「**课程与班级管理**」模块，作为整个学情监控体系的**组织基础**：通过课程与班级把学生、反馈、统计三个环节串联起来，让学情数据"有归属、可细分、可追溯"。

> 本模块方向为大作业清单 1.1.2 参考方向中的"教师课程与班级管理模块"，我在此基础上结合系统现状完成了具体需求与设计。

## 2. 功能设计（本人设计）

### 2.1 整体结构

采用 **课程 → 班级 → 学生名单** 三级钻取式结构：

```
我的课程（教师名下）
 └── 课程A
      ├── 班级A1（学生名单：可多选添加/移除）
      └── 班级A2（学生名单）
```

### 2.2 教师端功能

1. **课程管理**：新增课程（课程名、简介）、编辑课程、删除课程、查看名下课程列表；
2. **班级管理**：为课程创建班级、重命名班级、删除班级、查看班级学生名单；
3. **学生名单维护**：从全校学生列表中多选勾选加入班级（自动去重），或从班级中移除学生；
4. **归属隔离**：教师只能查看和操作自己名下的课程与班级，无法越权访问其他教师的课程（符合 PRD 权限隔离要求）。

### 2.3 学生端功能

1. **我的课程**：查看自己已加入的课程与所在班级；
2. **按课程反馈**：提交学情反馈时可选择所属课程，反馈记录归属到对应课程。

### 2.4 与主系统联动（关键设计）

- **统计升级**：学情定时统计由"全班一条"升级为"每门课程一条快照"，指标（人数/均分/方差/分布）按课程分别计算；
- **查询升级**：教师端实时统计与历史查询支持按课程筛选，历史导出可按课程导出；
- **反馈升级**：学生提交反馈带出课程归属，未选课程时归入"默认课堂"兜底，保证旧数据不丢失。

## 3. 数据结构（本人设计，AI 辅助细化）

新增 3 张数据表（详见 `database/schema.sql`）：

| 表名 | 说明 | 关键字段 |
|---|---|---|
| `course` | 课程表 | id、name 课程名、teacher_id 任课教师ID（外键→sys_user）、description 简介、create_time |
| `class_info` | 班级表 | id、name 班级名、teacher_id 所属教师ID（冗余，便于归属校验）、course_id 关联课程ID（外键）、create_time |
| `class_student` | 班级学生关联表 | id、class_id 班级ID、student_id 学生ID、create_time；**唯一约束(class_id, student_id)** 防止重复加入 |

设计要点：
- `class_info` 同时冗余 `teacher_id`，使归属校验不必跨表联查；
- `class_student` 用联合唯一键保证同一学生不能重复加入同一班级；
- 反馈表 `feedback` 增加可空 `course_id` 外键，兼容"默认课堂"场景；
- 删除课程采用**事务级联**：删除课程时自动清理其下班级与班级学生关联，已产生的反馈归入默认课堂保留，历史统计快照不删除（保证历史可追溯）。

## 4. 实现思路（AI 辅助实现，本人集成调试）

### 4.1 后端

- 新增 `CourseController` / `CourseManageService`：课程、班级、名单三级 CRUD；
- Service 层做**归属校验**：所有课程/班级操作先校验 `teacher_id = 当前登录教师`，不满足返回 403 语义错误；
- 添加学生接口：逐个校验学生存在性与角色（仅学生可加入），重复加入自动跳过并返回实际加入人数；
- 删除课程：`@Transactional` 事务内先删班级学生关联、再删班级、最后删课程；
- 新增 `StudentCourseController`：学生端查询自己加入的课程与班级（join class_student / class_info / course）。

### 4.2 前端

- 教师端 `home.html` 新增「课程班级」页签：三列钻取布局（课程列表 → 班级列表 → 学生名单），三个弹窗分别处理新增/编辑课程、新建班级、添加学生（多选勾选全校学生）；
- 学生端 `home.html` 新增「我的课程」页签：课程卡片展示课程名、任课教师、简介、班级标签；
- 反馈页与教师统计页的课程下拉数据源均来自本模块接口。

### 4.3 与既有模块的接入

- `FeedbackController` 提交接口增加 `courseId` 参数；
- `StatsService` 统计聚合改为按 `course_id` 分组；
- `StatisticsController` 实时/历史/导出接口增加课程筛选条件。
