## 1. 系统概述

课堂学情监控管理系统采用 **前后端一体** 的 Spring Boot 单体应用架构：



* **后端**：Java + Spring Boot 3.3 + MyBatis-Plus，提供 RESTful 接口

* **前端**：原生 HTML / CSS / JavaScript（ECharts 图表、Apache POI 导出 Excel），由 Spring Boot 直接托管静态资源

* **数据库**：MySQL 8.0（库名 `classcheck_system`，utf8mb4）

* **部署形态**：单机部署，访问 `http://localhost:8080`

## 2. 运行环境要求

## 4. 环境安装步骤

### 4.1 安装 JDK（推荐 21）



1. 下载 JDK 21（如 Oracle JDK 或 OpenJDK / 国内镜像）；

2. 安装后配置环境变量：

* `JAVA_HOME` = JDK 安装目录；

* 将 `%JAVA_HOME%\bin` 加入 `PATH`；

1. 验证：命令行执行 `java -version`，输出 `java 21.x` 即成功。

### 4.2 安装 MySQL 8.0



1. 安装 MySQL 8.0（社区版即可），安装时设置 root 密码（本项目使用 `123456`，可在 5.2 节按需修改）；

2. 确认 MySQL 服务已启动（Windows：服务管理器 → MySQL80 → 启动，或 `net start mysql80`）；

3. 验证：命令行执行 `mysql -uroot -p` 能进入 mysql 命令行即成功。

### 4.3 准备 Maven（可选）

项目已内置本地 Maven（`tools/apache-maven-3.9.9/`），也可使用自行安装的 Maven 3.6+。首次构建会自动下载依赖（已配置阿里云镜像加速）。

## 5. 数据库初始化

### 5.1 导入建表脚本

在命令行执行（脚本会自动创建数据库并导入测试数据，可重复执行）：



```
mysql -uroot -p < D:/classcheck\_system/database/schema.sql
```

或在 MySQL 客户端中执行：



```
source D:/classcheck\_system/database/schema.sql;
```

导入后包含 **8 张表**：`sys_user`、`course`、`class_info`、`class_student`、`feedback`、`statistics`、`discussion_message`、`sys_config`。

### 5.2 修改数据库账号（如需）

默认使用 `root / 123456`。如果你的 MySQL 密码不同，修改 `backend/src/main/resources/application.yml`：



```
spring:

&#x20; datasource:

&#x20;   url: jdbc:mysql://localhost:3306/classcheck\_system?useUnicode=true\&characterEncoding=utf8\&serverTimezone=Asia/Shanghai\&useSSL=false\&allowPublicKeyRetrieval=true

&#x20;   username: root        # 改为你的用户名

&#x20;   password: "123456"    # 改为你的密码
```

> 注意：本机若未安装 MySQL 8（或版本较低），需保证能使用 utf8mb4 字符集。

## 6. 后端启动

### 6.1 方式一：IDEA 启动（推荐）



1. 打开 IDEA → `File → Open`，选择 `backend/pom.xml`，以 Maven 项目导入；

2. 等待依赖下载完成（首次较慢）；

3. 打开 `com.classcheck.ClasscheckApplication`，点击运行按钮（或右键 → Run）；

4. 控制台出现 `Started ClasscheckApplication` 且端口 `8080` 监听即启动成功。

### 6.2 方式二：命令行启动

在项目根目录执行：



```
cd D:/classcheck\_system/backend

D:/classcheck\_system/tools/apache-maven-3.9.9/bin/mvn.cmd spring-boot:run
```

启动成功的标志：日志输出 `Tomcat started on port 8080`。

## 8. 常见问题排查



| 现象                 | 原因                      | 解决办法                                                                  |
| ------------------ | ----------------------- | --------------------------------------------------------------------- |
| 访问 8080 打不开        | 后端未启动                   | 按第 6 节启动，看日志是否有报错                                                     |
| 端口被占用              | 8080 被其他程序占用            | `netstat -ano \| findstr 8080` 找到 PID 结束进程；或修改 application.yml 的 port |
| 启动报数据库连接失败         | MySQL 未启动 / 密码错误 / 库不存在 | ①启动 MySQL 服务；②核对 application.yml 账号密码；③执行 schema.sql 建库               |
| `Unknown database` | 未导入脚本                   | 执行 `mysql -uroot -p < database/schema.sql`                            |
| 登录提示 "账号或密码错误"     | 输入错误或密码被改               | 用测试账号 `123456`；或让管理员在用户管理中重置密码                                        |
| 登录提示 "账号已禁用"       | 账号被管理员禁用                | 用 admin 登录后在用户管理中启用                                                   |
| 页面样式 / 图表不显示       | 浏览器缓存                   | 强制刷新（Ctrl+F5），或换 Chrome 无痕窗口                                          |
| 图片上传失败             | 格式 / 大小超限               | 仅支持 jpg/jpeg/png/gif/webp，≤10MB                                       |
| 中文乱码（控制台 / 导出）     | 编码问题                    | 全部文件 UTF-8；导出 Excel 用 Excel/WPS 打开                                    |
| 短信验证码收不到           | 演示环境模拟发送                | 页面会有验证码提示，直接使用页面展示的验证码                                                |
| 修改周期后不生效           | 未点保存                    | 保存后立即生效，无需重启；取值范围 5-10 分钟                                             |
