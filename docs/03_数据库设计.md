# 数据库设计

数据库：`classcheck_system`，字符集 `utf8mb4`。

## 表清单与关系

```
sys_user（用户表，含三类角色）
   ├── 1:n  feedback（学情反馈，按课程归属）
   ├── 1:n  discussion_message（讨论消息）
   ├── 1:n  course（教师名下课程，拓展模块）
   ├── 1:n  class_info（教师名下班级，拓展模块）
   └── 1:n  class_student（班级-学生关联，拓展模块）

course（课程） ── 1:n ── class_info（班级）
class_info ── 1:n ── class_student（班级学生名单）
feedback ── n:1 ── course（反馈关联课程，为学情按课程统计提供依据）

statistics（学情统计快照）：每个统计周期每个课程一条快照
sys_config（系统参数：统计周期等）
```

## 各表字段说明

### 1. sys_user 用户表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AI | 用户编号（PRD 中"编号"） |
| username | VARCHAR(50) UNIQUE | 登录账号 |
| password | VARCHAR(100) | 密码（MD5 加盐存储） |
| name | VARCHAR(50) | 姓名 |
| role | TINYINT | 角色：1 学生 / 2 教师 / 3 管理员 |
| age | INT | 年龄 |
| gender | VARCHAR(10) | 性别 |
| phone | VARCHAR(20) | 联系方式（兼作短信验证码接收号） |
| student_no | VARCHAR(30) | 学号（学生专属） |
| grade | VARCHAR(20) | 年级（学生专属） |
| class_name | VARCHAR(30) | 班级（学生专属，默认班级） |
| major | VARCHAR(50) | 专业（学生专属） |
| status | TINYINT | 账号状态：1 正常 / 0 禁用 |
| create_time | DATETIME | 创建时间 |

### 2. feedback 学情反馈表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AI | 反馈 ID |
| student_id | BIGINT FK→sys_user | 学生 ID |
| score | TINYINT | 分值 1-6（对应 6 档表情） |
| course_id | BIGINT FK→course | 所属课程（拓展模块联动，可为空=默认课堂） |
| create_time | DATETIME | 提交时间 |

### 3. statistics 学情统计快照表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AI | 统计 ID |
| stat_time | DATETIME | 统计时间（快照时刻） |
| course_id | BIGINT FK→course | 课程（可为空=默认课堂） |
| course_name | VARCHAR(100) | 冗余课程名，便于按课程名查询 |
| total_count | INT | 提交表情的学生总人数（按学生去重，取最新反馈） |
| avg_score | DECIMAL(4,2) | 班级平均分 |
| variance | DECIMAL(10,4) | 分数方差（总体方差） |
| score1_count..score6_count | INT ×6 | 各分数段（对应表情）分布人数 |
| create_time | DATETIME | 入库时间 |

### 4. discussion_message 讨论消息表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AI | 消息 ID |
| sender_id | BIGINT FK→sys_user | 发送人 ID |
| content | TEXT | 文字内容 |
| image_url | VARCHAR(255) | 图片地址（可空） |
| create_time | DATETIME | 发送时间 |

### 5. sys_config 系统参数表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AI | 配置 ID |
| config_key | VARCHAR(50) UNIQUE | 配置键（如 stats_period_minutes） |
| config_value | VARCHAR(100) | 配置值 |
| update_time | DATETIME | 更新时间 |

### 6. course 课程表（拓展模块）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AI | 课程 ID |
| name | VARCHAR(100) | 课程名称 |
| teacher_id | BIGINT FK→sys_user | 任课教师 ID |
| description | VARCHAR(255) | 课程简介 |
| create_time | DATETIME | 创建时间 |

### 7. class_info 班级表（拓展模块）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AI | 班级 ID |
| name | VARCHAR(50) | 班级名称 |
| teacher_id | BIGINT FK→sys_user | 所属教师 |
| course_id | BIGINT FK→course | 关联课程 |
| create_time | DATETIME | 创建时间 |

### 8. class_student 班级学生关联表（拓展模块）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK AI | 关联 ID |
| class_id | BIGINT FK→class_info | 班级 ID |
| student_id | BIGINT FK→sys_user | 学生 ID |
| create_time | DATETIME | 加入时间 |
| 唯一约束 | (class_id, student_id) | 防止重复加入 |

完整建表 SQL 与初始化测试数据见 `database/schema.sql`。
