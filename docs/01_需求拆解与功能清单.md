# 需求拆解与功能清单

> 依据：《课堂学情监控管理系统产品要求文档》（PRD）
> 说明：本清单严格对齐 PRD 原文，未扩展文档外需求；「拓展」标注为本人自主新增模块「课程与班级管理」的相关功能。

## 一、学生端（移动端 / PC 端浏览器）

| 编号 | 功能点 | 对应 PRD |
|---|---|---|
| S1 | 提交 6 档表情学情反馈，6 档表情一一对应 1-6 分（6=完全理解，1=完全没理解），提交当前课程理解状态 | 5.1 |
| S2 | 在课堂在线讨论区发送文字、图片消息，参与实时互动 | 5.4 |
| S3 | 通过三种方式登录系统：密码认证、短信验证码认证、第三方账号认证（微信 / QQ） | 5.6 |
| S4 | （拓展）选择自己所在课程后再提交反馈，反馈归属到具体课程 | 拓展模块 |
| S5 | （拓展）查看自己已加入的课程与班级列表 | 拓展模块 |

## 二、教师端（PC 端浏览器）

| 编号 | 功能点 | 对应 PRD |
|---|---|---|
| T1 | 查看当前时段学情统计结果，指标包含：提交表情的学生总人数、各分数段（对应表情）分布人数、班级平均分数、分数方差 | 5.2 |
| T2 | 统计结果以数字、表情、图表三种形式展示，图表包含柱状图、饼状图两类 | 5.2 |
| T3 | 按上课时间、课程名称两个维度组合查询历史学情统计数据 | 5.3 |
| T4 | 将查询结果导出为 Excel 格式文档 | 5.3 |
| T5 | 参与课堂在线讨论区，发送文字、图片消息 | 5.4 |
| T6 | （拓展）维护自己名下的课程（增、删、改、查） | 拓展模块 |
| T7 | （拓展）维护自己名下的班级，并为班级添加/移除学生 | 拓展模块 |

## 三、管理员端（PC 端浏览器）

| 编号 | 功能点 | 对应 PRD |
|---|---|---|
| A1 | 对学生、教师、管理员三类用户执行添加、删除、修改、查询 | 5.5 |
| A2 | 学生用户字段：编号、学号、姓名、年龄、性别、年级、班级、专业、联系方式 | 5.5 |
| A3 | 教师 / 管理员用户字段：编号、姓名、年龄、性别、联系方式 | 5.5 |
| A4 | 配置学情统计刷新周期，取值范围 5-10 分钟 | 5.2 |

## 四、系统公共

| 编号 | 功能点 | 对应 PRD |
|---|---|---|
| C1 | 所有功能必须经过身份认证后方可使用，禁止匿名访问业务数据 | 6.3 |
| C2 | 不同角色权限隔离，禁止越权操作 | 6.3 |
| C3 | 按管理员配置的周期（5-10 分钟）自动统计全班学情数据 | 4 / 5.2 |
| C4 | 支持 200 人同时在线；核心操作响应 < 1 秒 | 6.1 |

## 五、开发顺序建议（依赖关系）

1. 数据库设计 → 2. 项目骨架 → 3. 登录认证（C1/C2 前置）→ 4. 学情反馈（S1）→ 5. 定时统计（C3/T1/T2）→ 6. 历史查询与导出（T3/T4）→ 7. 讨论区（S2/T5）→ 8. 用户管理（A1-A4）→ 9. 拓展模块：课程与班级管理（S4/S5/T6/T7）→ 10. 联调与文档
