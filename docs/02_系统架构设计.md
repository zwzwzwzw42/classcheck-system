# 系统架构设计

## 1. 技术选型

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | Java 21 + Spring Boot 3.3 + MyBatis-Plus | 课程作业常用主流栈，与指导手册示例一致 |
| 数据库 | MySQL 8.0（utf8mb4） | 本机已装 MySQL 8.0.37 |
| 前端 | 原生 HTML + CSS + JavaScript + ECharts | 手册要求的前端形态，无需构建工具，浏览器直接运行 |
| Excel 导出 | Apache POI | 生成 .xlsx |
| 构建 | Maven 3.9（本地 tools 目录 + 阿里云镜像） | 已配置 |
| 会话 | Token（内存存储）+ 登录拦截器 | 轻量，满足课程作业并发与安全要求 |

## 2. 分层架构

```
┌─────────────────────────────────────────────┐
│ 前端（浏览器）                               │
│  学生端 / 教师端 / 管理员端  HTML+JS+ECharts │
└──────────────┬──────────────────────────────┘
               │ HTTP / JSON（fetch）
┌──────────────▼──────────────────────────────┐
│ 表现层 Controller：接收请求、参数校验、返回JSON│
├─────────────────────────────────────────────┤
│ 业务层 Service：核心业务逻辑                 │
│  （学情统计计算、权限校验、定时统计调度等）     │
├─────────────────────────────────────────────┤
│ 数据访问层 Mapper：数据库 CRUD（MyBatis-Plus）│
├─────────────────────────────────────────────┤
│ 实体层 Entity：与数据库表对应的 Java 对象     │
└─────────────────────────────────────────────┘
```

## 3. 功能模块划分

| 模块 | 职责 | 核心类 |
|---|---|---|
| 认证模块 | 登录（密码/短信/第三方模拟）、Token 签发、会话校验、角色权限拦截 | AuthController / AuthService / LoginInterceptor |
| 学情反馈模块 | 学生表情提交（1-6 分）、按课程归属 | FeedbackController / FeedbackService |
| 学情统计模块 | 定时统计调度（周期 5-10 分钟可配）、指标计算（人数/分布/平均分/方差）、快照存储 | StatsTask / StatisticsService / SchedulingConfigurer |
| 历史查询模块 | 按课程+时间组合查询、Excel 导出 | StatisticsController（查询+导出） |
| 在线讨论模块 | 文字/图片消息发送、拉取、图片上传 | DiscussionController / FileController |
| 用户管理模块 | 管理员对三类账号增删改查 | UserManageController |
| 系统配置模块 | 统计周期参数配置与读取 | ConfigController / SysConfigService |
| 拓展模块：课程与班级管理 | 课程增删改查、班级管理、班级学生名单维护 | CourseController / ClassController / CourseService |

## 4. 前后端交互约定

- 前端通过 `fetch` 调用后端 RESTful 接口；
- 所有接口返回统一 JSON：`{ "code": 0, "message": "ok", "data": ... }`，code=0 表示成功，非 0 表示业务失败（401 未登录/未授权）；
- 登录后前端在请求头携带 `Authorization: Bearer <token>`；
- 静态页面与图片上传目录由 Spring 静态资源映射对外提供访问。

## 5. 定时统计机制

- 实现 `SchedulingConfigurer`，每次调度前从 `sys_config` 表读取统计周期（管理员可配 5-10 分钟）；
- 到达周期时，对每个课程统计：取每位学生在该课程的最新一次反馈 → 计算提交人数、各分数人数、平均分、方差 → 写入 `statistics` 表作为历史快照；
- 教师端"当前时段"展示最近一次统计快照，"历史查询"按课程+时间范围检索快照记录。

## 6. 权限模型

- 角色：学生(1) / 教师(2) / 管理员(3)；
- 登录拦截器校验 Token 与登录态；接口级按角色控制（如 `/api/admin/**` 仅管理员）；
- 教师仅能管理自己名下的课程与班级；学生仅能提交反馈与参与讨论。
